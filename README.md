# Statistic-and-A-B-testing
Проект по математической статистике и A/B-тестированию в рамках
группового проекта НИУ ВШЭ.

## О проекте

Проект состоит из двух аналитических частей:

1.  **A/B-тестирование** --- анализ эксперимента с двумя версиями
    лендинга образовательного сервиса.
2.  **Проверка статистических гипотез** --- исследование факторов,
    связанных с успешным завершением обучения студентами.

В работе используются EDA, проверка корректности экспериментальных
групп, A/A-тестирование, bootstrap, временной анализ, t-test, z-test,
permutation test, критерий Манна--Уитни, критерий Краскала--Уоллиса и
χ²-тест.

Основные этапы:

-   первичный EDA;
-   проверка типов данных и пропусков;
-   проверка соответствия экспериментальной группы и версии лендинга;
-   анализ размера и однородности групп;
-   анализ временной составляющей эксперимента;
-   A/A-тестирование;
-   выбор конверсии (`converted`) в качестве основной метрики;
-   bootstrap-сравнение групп;
-   анализ временных рядов и автокорреляции;
-   проверка гипотез с помощью t-test;
-   проверка равенства дисперсий критерием Левена;
-   z-test для сравнения пропорций;
-   permutation test;
-   итоговая оценка статистической значимости изменения.


В анализе рассматриваются три гипотезы:

1.  Возраст при поступлении у отчисленных студентов выше, чем у
    выпускников.
2.  Средний балл при поступлении у выпускников выше, чем у отчисленных.
3.  Уровень образования родителей статистически связан с вероятностью
    выпуска студента.

Для проверки используются:

-   EDA и визуализация распределений;
-   тест Шапиро--Уилка;
-   критерий Манна--Уитни;
-   критерий Краскала--Уоллиса;
-   χ²-тест независимости.

Итоговый вывод ноутбука: возраст при поступлении и балл при поступлении
связаны с различием между выпускниками и отчисленными студентами, тогда
как наличие высшего образования у родителей статистически значимой связи
с результатом обучения в проведённом тесте не показало.


## Основные результаты

### A/B-тест

Анализ нескольких статистических процедур не выявил статистически
значимых различий между контрольной и экспериментальной группами по
выбранной метрике конверсии.

Для проверки результата использовались несколько независимых подходов,
включая bootstrap, t-test, z-test и permutation test.

### Статистические гипотезы по студентам

Исследование показало статистически значимое различие по возрасту при
поступлении между отчисленными и выпускниками, а также различие по баллу
при поступлении.

Проверка связи с наличием высшего образования у родителей статистически
значимой зависимости не выявила.

## Ограничения и возможные улучшения

Для дальнейшего улучшения проекта можно:

-   вынести повторяющиеся операции подготовки данных в отдельные
    функции;
-   убрать дублирующий импорт `mannwhitneyu` во втором ноутбуке;
-   вынести версии библиотек в `requirements.txt`;
-   добавить единый `.gitignore`;
-   добавить явное описание источников и лицензий датасетов;
-   привести формулировки статистических выводов к более строгой
    терминологии: вместо «принимаем H₀» использовать «нет оснований
    отвергать H₀»;
-   добавить количественную оценку эффекта и доверительные интервалы
    там, где это необходимо для оценки практической значимости.
